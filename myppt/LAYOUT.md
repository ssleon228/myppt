# 版面积木（实验版）

内容页可以不写版面，程序会按页型和内容量自己设计（推荐）。
想自己设计某一页时，加一个 `layout` 字段，或者用 `"type": "free"` 页（内容全部写在 layout 里）。

**你只决定「怎么分块、每块放什么」。坐标、字号、宽度、间距、颜色值全部由程序算。**
写了坐标、字号、颜色值会被丢掉；版面放不下或太空，程序会改用自己的设计。

## 容器

```json
{"box": "row", "children": [...], "gap": "s|m|l", "w": 1-12, "style": "卡片样式", "pad": "s|m|l"}
```

- `row` 横排（最多 4 个），`col` 竖排（最多 7 个），`grid` 网格（加 `"cols": 2|3`）
- `w`：在横排里占的份数（可不写，程序按内容量分）
- `style`：`none`（默认）`soft`（浅色底）`outline`（细框）`topbar`（白卡+顶部色条）`leftbar`（左侧色条）`accent`（主色底，文字反白）`dark`（深色底）
- 一页最多 14 个元素，最多嵌套 4 层

## 元素

| el | 字段 | 用途 |
|---|---|---|
| heading | text, kicker（小标签）, sub（副说明）, role: h1/h2/lead | 小标题 |
| text | text, role: h2/lead/body/small, color, bold | 一段话 |
| bullets | items（字符串或 {head, text}）, marker: dot/num/check/icon/bar/none | 要点 |
| kpi | value（只放数字+单位）, label, delta（如 "+16 个百分点"）, icon | 大数字 |
| iconitem | icon, head, text, layout: top/left | 图标+标题+说明 |
| step | n（如 "01"）, head, text, layout: top/left | 步骤 |
| quote | text, by | 金句 |
| callout | text | 结论条（主色底） |
| chart | chart（同 chart 页） | 图表，自动占满剩余空间 |
| table | headers, rows, highlight（行号） | 表格 |
| image | src（真实图片路径）, fit: cover/contain | 图片 |
| divider / spacer | — | 分隔线 / 留白 |

`color` 只能写角色名：ink、muted、primary、accent、white、good、warn、dark。

## 例子

```json
{"type": "free", "title": "新能源车贷已成为增长主引擎",
 "layout": {"box": "row", "gap": "l", "children": [
   {"box": "col", "w": 5, "children": [
     {"el": "kpi", "value": "54%", "label": "新增放款中新能源占比", "delta": "+16 个百分点", "style": "accent", "pad": "l"},
     {"el": "kpi", "value": "4.1亿元", "label": "主机厂贴息专案放款", "style": "leftbar"}]},
   {"box": "col", "w": 7, "children": [
     {"el": "heading", "kicker": "为什么增长快", "text": "政策、价格、渠道三重利好叠加"},
     {"el": "bullets", "marker": "check", "items": [{"head": "政策", "text": "以旧换新补贴延续至年底"}]},
     {"el": "callout", "text": "建议四季度新能源专案额度再增加 2 亿元"}]}]}}
```

## 程序怎么把关

1. 校验：不认识的元素报错，档位写错改回默认，一行超过 4 个自动折成网格。
2. 排版：字号档位从大到小试，取放得下的最大一档（字少就放大，字多就缩小，最小 12 磅）。
3. 检查：溢出、填充率（太空）、并排几栏内容量悬殊、卡片里一半是空的、元素太多。
4. 不合格：改用程序自己的设计；还不行就用原来的版式。出稿报告里每页写明用了哪种。

## 从人工模板学来的设计手法（全部由程序自动做，模型不用管）

参考 AiPPT 这类人工设计模板，挑出「机器能稳定做对」的手法，写成程序规则：

| 手法 | 程序怎么做 | 哪些风格用 |
|---|---|---|
| 数字高亮 | 正文里带单位的数据（37 家、12.6 亿元、58%）自动加粗上主色；年份、月份、4S、Q3 这类不算 | 全部 |
| 水印大序号 | 一组 3–6 张同尺寸、同样式的卡片，右上角铺很淡的大号 01/02/03；卡片里已有编号、指标、图表时不加 | 商务、圆润、大色块、科技 |
| 主次突出 | 一排 ≥3 张指标卡，第一张换主色实底（头号指标），其余浅色 | 商务、圆润、科技 |
| 骑缝衔接箭头 | 步骤卡片之间画骑在缝上的小圆箭头，表示先后顺序 | 全部（步骤卡片版式） |
| 图标大圆串联 | 新元素 `orbs`：大圆图标 + 骑缝序号 + 连线，3–5 个并列或递进要点 | 全部，圆润/典雅优先 |
| 说明卡撑满 | 流程箭头、时间轴下方有富余高度时，每步下面放一张说明卡（按风格画浅色块/细线/细框） | 全部 |
| 空白带检查 | 页面竖向上有一整条 >15% 页高的空白就扣分，换别的搭法 | 全部 |

还检查：顶层是一排卡片时不再被拉满整页（按列的规则最多长高 15% 后居中）。
