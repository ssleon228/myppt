# AI 设计模板（实验版）

不用现成模板时，在 deck.json 顶层写 `brand`，程序会画出整套模板：封面、目录、章节页、封底、内容页 Banner，
配色同时用到所有内容页和图表。**你只回答下面几个选择题，其余全部由程序决定**（具体颜色值、位置、大小、对比度）。
全部字段都可以省，省了程序按气质或标题自己定。

```json
"brand": {"org": "零售金融部", "mood": "稳重 金融", "cover": "diagonal", "pattern": "dots"}
```

| 字段 | 可选值 | 说明 |
|---|---|---|
| org | 文字 | 汇报单位，用在标志和封底；不知道就不写（不会编） |
| mood | 气质词 | 稳重/金融/银行/科技/数字化/政务/党建/绿色/ESG/高端/私行/医疗/教育/咨询/简约/营销/活力/工业… 程序据此挑色板和封面 |
| palette | 下表色板 id | 想指定色板时写 |
| primary | 主色，如 "0B4F9C" | 用户给了品牌色时写；程序据此推导整套配色并修正到耐看、对比度达标 |
| cover | diagonal 斜切深色 / split 左右分屏 / arcs 白底圆弧 / band 横带 / frame 深色边框居中 / mosaic 色块拼贴 | 封面构图，同时决定章节页、Banner 和底纹的默认风格 |
| style | corporate 商务稳重 / rounded 圆润亲和 / editorial 杂志留白 / bold 大色块 / luxury 典雅细框 / tech 科技网格 | 设计语言：决定所有内容页怎么画（卡片、图标、要点符号、结论条、留白、页面底色、目录样式）以及同一页优先挑哪种构图。不写就按封面配套：diagonal→商务、split→圆润、arcs→杂志、band→大色块、frame→典雅、mosaic→科技 |
| pattern | dots 点阵 / lines 斜线 / waves 波浪 / hex 六边形 / grid 网格 / none | 底纹 |
| banner | bar 整条色带 / line 白底细线 / tab 左侧色签 | 内容页标题栏，一般不用写 |
| logo | 图片路径 | 用户提供的 logo；没有就用「首字方印 + 单位名」文字标志 |
| image | 图片路径 | 封面照片（split 构图用），没有就用程序生成的几何图形 |
| motif | 图标 id | 封面装饰图标，不写按标题关键词自动选（209 个内置图标） |

## 程序把关

- 写错的选项改回默认并在出稿报告里说明；logo、照片文件找不到就改用程序生成的素材。
- 配色统一过对比度检查：白字压主色 ≥ 4.5，正文 ≥ 12，次要文字 ≥ 4.5，不达标自动加深。
- 点缀色只用于小面积强调（短色条、圆点、个别色块），不会大面积铺。
- 所有图形都是 PowerPoint 原生矢量形状，可编辑；字体默认用常见的微软雅黑（Mac、WPS 会自动换成同类黑体），不要求安装任何字体；brand 里可以写 "font" 换成别的字体。用户模板路线的字体跟随用户模板。
